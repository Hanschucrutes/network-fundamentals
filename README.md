# Network Fundamentals

Repositório de estudos práticos sobre fundamentos de redes de computadores, com foco na construção de uma base para atuar em **Cibersegurança** e, futuramente, em um **SOC (Security Operations Center)**.

> Este repositório registra minha jornada de aprendizagem. Os conteúdos serão atualizados conforme avanço nos estudos e realizo atividades práticas.

## Objetivos

- Compreender como dispositivos se comunicam em uma rede.
- Aprender conceitos de endereçamento IP, DNS, DHCP, portas e protocolos.
- Conhecer os modelos OSI e TCP/IP.
- Desenvolver uma base para estudar monitoramento de redes e análise de eventos de segurança.
